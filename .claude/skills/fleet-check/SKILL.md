# fleet-check

1. Из корня репозитория запусти (таймаут 600000 мс; gradle при первом запуске качает зависимости):
   ```bash
   .claude/skills/fleet-check/check.sh            # всё
   .claude/skills/fleet-check/check.sh --no-smoke # без docker compose, для промежуточных прогонов (promtool остаётся)
   ```
   Скрипт сам делает `source scripts/env.sh`, пишет логи в отдельный временный каталог и печатает таблицу.
   Код выхода 1 — хоть одна проверка упала или не смогла запуститься.
2. Покажи пользователю таблицу как есть. Для каждой ❌ прочитай хвост лога (`tail -n 60 <лог>`), назови
   причину одной фразой и укажи файл:строку, если она видна.
3. Не считай шаг выполненным, если есть ❌ или ⏭ из-за отсутствующего окружения (нет `local.properties`,
   нет venv, нет доступа к docker). ⏭ «сервиса/сценария/алертов ещё нет» допустим только на ветках без этой части.
4. Не чини окружение молча: нет SDK → предложи `scripts/setup.sh --no-emulator`; нет venv → команду из таблицы.

Чего проверка не покрывает (всегда перечисляй в отчёте как ручные): реальные модели OpenRouter и GigaChat, реальный
AutoGRAPH, настоящий бот Telegram, приложение на устройстве/эмуляторе (на этой машине нет /dev/kvm), уведомления.
